Programación en Java

Cuento con 5 años de experiencia desarrollando software con Java, siendo este el lenguaje de programacion que mejor domino hasta el día de hoy. Me mantengo actualizado en el lenguaje, utilizando características modernas como Records y Optional, así como la API de Streams para el procesamiento declarativo y eficiente de datos en colecciones.

Desarrollo con framework Spring

Cuento con más de 4 años de experiencia trabajando con Spring Boot, siendo el framework en el que tengo mayor dominio. Manejo ampliamente la inyección de dependencias, así como Spring Data y su submódulo JPA. Tengo experiencia en la creación de APIs REST con Spring Web y conocimientos básicos en Spring Batch, Spring Security y Spring Cloud, este último aplicado en el desarrollo de arquitecturas de microservicios.

Dominio de Bases de Datos SQL

Cuento con sólidos conocimientos en bases de datos relacionales como MySQL, PostgreSQL, Oracle y SQL Server. Manejo programación en PL/SQL para implementar lógica de negocio en la base de datos, incluyendo la creación de triggers, jobs y procedimientos almacenados.
